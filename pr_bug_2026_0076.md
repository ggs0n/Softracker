## Summary
- persist pending Stripe checkout session state on the user record
- reconcile pending checkout state on payment page refresh to avoid inconsistent retry/paid/unpaid UI
- reuse existing open checkout instead of creating a second Stripe checkout session
- clear pending checkout state on successful payment or cancel
- add regression tests for resume, pending refresh, and completed refresh reconciliation
